About This Project

College Web Dev

StudyNest is a college front-end web development project created by a 2nd-year B.Tech student. It is built strictly using standard HTML5, CSS3, and vanilla JavaScript without external frameworks, Node.js dependencies, or backend databases.

How Edits are Saved: All user customizations — including adding or editing study resources, modifying timetable slots, and checking off study tasks — are stored inside your browser's localStorage, separately for each logged-in student. Student accounts (Login / Register) are stored in a SQLite database on the Python server.
